本地文件播放

管线为 FileSource → FFmpegDemuxer → FFmpegSwDecoder → AlsaSink。解码线程在会话生命周期内只创建一次。控制线程只改标志。

1. 打开与读包

FFmpegDemuxer 使用 AVFMT_FLAG_CUSTOM_IO，字节来自 DataSource。存在音频流时必须打开 ALSA PCM 设备，输出为交错 S16，采样率取协商结果。无音频流时按视频 PTS 调度，视频帧在 receive 后释放，不送显示 Sink。

2. 主时钟与流结束

音频主时钟为 origin_us + (written_frames - snd_pcm_delay) * 1000000 / rate。首次写入成功调用 media_first_frame，state 转为 playing。EOF 之后取出重采样残余样本，再 snd_pcm_drain。drain 期间若暂停或 Seek 已经置位，不发送 EOS。

3. 传输控制

暂停调用 AlsaSink::drop。设备欠载才 snd_pcm_recover。stop_and_join 不能在持有 Player::mu_ 时执行，因为 media_first_frame 需要同一把锁。
