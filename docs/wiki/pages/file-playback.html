本地文件播放

管线为 FileSource → FFmpegDemuxer → 每路包队列 → FFmpegSwDecoder → PCM 环或帧队列 → 音频输出线程。打开在会话 IO 线程上。控制线程只改标志。

1. 打开与队列

FFmpegDemuxer 使用 AVFMT_FLAG_CUSTOM_IO，字节来自 DataSource。解复用线程按流把包放进队列。时长上限是预设的 buffer_max_s，字节上限是这个秒数乘以 1 MiB/s。视频帧队列容量 8。包和帧带 serial。存在音频流时必须打开 ALSA PCM 设备，输出为交错 S16。视频帧不送显示 Sink。

2. 主时钟与流结束

音频输出线程从 PCM 环取出样本再写入设备。音频主时钟为 origin_us + (written_frames - snd_pcm_delay) * 1000000 / rate。首次写入成功调用 media_first_frame。EOF 之后取出重采样残余样本，再 snd_pcm_drain。drain 期间若暂停或 Seek 已经置位，不发送 EOS。

3. 传输控制

暂停调用 AlsaSink::drop。设备欠载才 snd_pcm_recover。包队列见底时 state 变为 buffering，stall_count 加一。FilePlayback::stop 不能在持有 Player::mu_ 时执行，因为音频输出线程回调 media_first_frame 需要同一把锁。
