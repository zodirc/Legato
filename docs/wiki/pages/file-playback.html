本地文件播放

管线为 FileSource → FFmpegDemuxer → 每路包队列 → FFmpegSwDecoder → PCM 环或帧队列 → 音频输出线程。打开在会话 IO 线程上。Player::io_main 注入 AudioMasterClock 和 AlsaSink；没有音频流时改为 MonotonicClock。控制线程只写 serial 和目标位置。

1. 打开与队列

FFmpegDemuxer 使用 AVFMT_FLAG_CUSTOM_IO，字节来自 DataSource。解复用线程按流把包放进队列。时长上限是预设的 buffer_max_s，字节上限是这个秒数乘以 1 MiB/s。视频帧队列容量 8。包和帧带 serial。存在音频流时必须打开 ALSA PCM 设备，输出为交错 S16。视频帧交给 CountingVideoSink，只计数，不画。

2. 主时钟与流结束

音频输出线程从 PCM 环取出样本再写入设备。主时钟只在 AudioMasterClock::observe_delay 计算，公式是 origin_us + (written_frames - delay_frames) * 1000000 / rate。首次写入成功后，输出线程把首帧写入通知环，控制线程调用 media_first_frame。EOF 之后取出重采样残余样本，再 snd_pcm_drain。drain 期间若暂停或 Seek 已经置位，不发送 EOS。输出线程看到新 serial 后清零写入帧数和首帧标记。

3. 传输控制

暂停调用 AudioSink::drop。设备欠载才 snd_pcm_recover。包队列见底时输出线程写入卡顿通知，控制线程把 state 变为 buffering，stall_count 加一。FilePlayback::stop 不能在持有 Player::mu_ 时执行，因为解复用线程调用 media_failed 需要同一把锁。输出线程不拿这把锁。
