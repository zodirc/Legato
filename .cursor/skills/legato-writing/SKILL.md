# Legato 写作标准

编写或修改本仓库的 README、文档和代码注释时执行本标准。先替换名词，再组织段落。不要解释项目名称的来源。

## 口吻

- 使用播放引擎的技术书面语。句子给出对象、动作和条件。
- 中文文档与注释使用本标准的名词。符号、函数、协议字段、错误字符串保持代码中的原文。
- 开篇用一句话定义对象，然后进入流程、字段和验证。不写宣传句，不写名称典故。
- 同一概念全文只用一个名词。代码里的字面量（如 `headless-skeleton`、`这个协议还不能播`）用反引号照抄，并在首次出现时说明含义。

## 名词

| 使用 | 不使用 |
|---|---|
| 播放引擎 | 播放器框架、内核骨架 |
| 解复用 | 拆包、解封装（文档中） |
| 解码 | 软解（除非特指软件解码器） |
| 会话 | 播放实例的口语说法 |
| 控制线程 | 控制 actor（文档中） |
| 解码线程 | 工作线程 |
| 主时钟、音频主时钟 | 播放进度的口语说法 |
| 虚拟媒体时钟 | 无头时钟 |
| 呈现时间戳（PTS） | 时间戳（未指明种类时） |
| 首帧时延 | 首帧毫秒数、骨架时序 |
| 流结束（EOS） | 播完、放完 |
| Seek | 拖动、跳播 |
| 显示 Sink | 窗口、出画 |
| ALSA PCM 设备 | 声卡（文档中；错误字符串除外） |
| PCM 输出 | 出声 |
| 单调时钟 | 墙钟 |
| 确定性回归 | 无头基准、无头路径、无头模式 |
| 基线（golden） | 黄金文件、黄金结果 |
| 示例程序 | 演示、demo（文档正文） |
| 切换媒体项 | 换片 |
| 设备欠载（XRUN） | 卡顿、断一下 |
| 预设 | 模式（指 `vod` / `short_video` / `music` 时） |

`corpus://` 称为确定性回归的用例标识，不称为样本或假媒体。`legato_engine_advance_us` 称为测试对虚拟媒体时钟的推进。

## 代码注释

- 注释使用中文，名词与上表一致。
- 只注释不变量、锁顺序、线程边界、协议选择和失败后的状态。代码已经表达的动作不注释。
- 注释说明原因。例如：持有 `Player::mu_` 时不能 join 解码线程，因为回调 `media_first_frame` 需要同一把锁。
- 不在注释中重述文档段落，不写待办口号。

## 文档

面向需要沿调用链核对行为的开发者。结构固定为三段：

1. 代码流程：入口、分发条件、主路径、传输控制。每步写调用点和状态变化。
2. 字段对应：`对外字段 <- 引擎字段 <- 产生位置`。运行时生成的值写明函数。
3. 构建、目录与验证：编译条件、交付件、退出码和核对步骤。文末给出代码依据，格式为 `符号 <- 路径`。

标题用 `## 1.`、`### 1.1`。步骤使用有序列表，要点使用粗体引导语。大节之间用 `---`。文首写项目定义和三段目录，并附：

```markdown
> 最后更新时间：YYYY-MM-DD
> 基于路径：`Legato`
```

修改文档行为时同步更新日期。不链接被忽略的设计稿。流程架构导览放在 `docs/wiki/`，用浏览器打开 `docs/wiki/index.html`。

## 流程图

`docs/wiki/assets/**/*.png` 是主链详流，不是说明卡片，也不是信息图。样板是 `docs/wiki/assets/file-playback-zh.png`。新增或替换任何一张图之前，先打开样板对照，不要另起一套皮肤。

一张图固定为五区：

| 区 | 职责 |
|---|---|
| 顶 | 居中标题，一行灰色副标题 |
| 左辅栏 | 入口、触发，或本路径不创建的对象。虚线框里是白底小格 |
| 中主链 | 一条垂直脊柱。宽而矮的条带、左缘编号圆、画出来的箭头 |
| 右辅栏 | 失败、旁路、禁止项。不是第二条主链 |
| 底 | 红色「要点：」横条，用 `｜` 分隔。页脚是该 PNG 的仓库相对路径 |

判定用黄菱形，出边写「是」「否」。读者应先看见中间的箭头链。满页等大色块、只靠文字充当箭头，都要重画。

图内符号、函数名和错误字符串与代码一致。冲突时以代码为准，其次是导览正文，最后才是图上的字。

禁止把下列产物当作正文图：Mermaid、Graphviz、等重卡片循环、Unicode `↓` 脊柱、在旧 PNG 上涂改。替换时整张重绘为 1536×1024 的 RGB PNG。

导览页是 `docs/wiki/pages/*.html` 里的 `<section class="page">`。图放在 `<figure class="figure">` 中，由 `docs/wiki/index.html` 分页加载。图注写「点击放大」。正文用本标准的名词，步骤写调用点和状态，不把图上的句子再抄一遍。
